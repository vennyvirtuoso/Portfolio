Implementation & Optimization Highlights

Explore the exact Triton `@triton.jit` implementation code for Fused Soft-Dice Loss, Fused Softmax, and Vector Addition.

kernels/soft_dice_loss.py Language: Python / Triton C-like JIT 
import torch
import triton
import triton.language as tl

# Fused Soft-Dice Loss Kernel for 3D/2D Medical Tensors
# Key Innovation: 2D Block Grid + Lock-Free tl.atomic_add for multi-block spatial reduction
@triton.jit
def _soft_dice_kernel(
    pred_ptr, target_ptr,
    inter_ptr, pred_sum_ptr, target_sum_ptr,  # Output reduction buffers
    n_elements,                              # Elements per (B, C) slice (~260K+ elements)
    BLOCK_SIZE: tl.constexpr,
):
    pid = tl.program_id(0)      # Axis 0: Spatial chunk index
    row_id = tl.program_id(1)   # Axis 1: Batch * Channel slice index

    block_start = pid * BLOCK_SIZE
    offsets = block_start + tl.arange(0, BLOCK_SIZE)
    mask = offsets < n_elements

    base = row_id * n_elements
    pred = tl.load(pred_ptr + base + offsets, mask=mask, other=0.0)
    target = tl.load(target_ptr + base + offsets, mask=mask, other=0.0)

    # Compute partial sums in SRAM registers without global DRAM roundtrips
    inter = tl.sum(pred * target, axis=0)
    p_sum = tl.sum(pred, axis=0)
    t_sum = tl.sum(target, axis=0)

    # Atomic accumulation across cooperating spatial blocks
    tl.atomic_add(inter_ptr + row_id, inter)
    tl.atomic_add(pred_sum_ptr + row_id, p_sum)
    tl.atomic_add(target_sum_ptr + row_id, t_sum)
kernels/fused_softmax.py Single-Pass In-Register Row Reduction 
@triton.jit
def _softmax_kernel(
    out_ptr, in_ptr,
    in_row_stride, out_row_stride,
    n_cols,
    BLOCK_SIZE: tl.constexpr,  # Pow2 padded block size
):
    row_idx = tl.program_id(0)
    row_start_ptr = in_ptr + row_idx * in_row_stride
    col_offsets = tl.arange(0, BLOCK_SIZE)
    input_ptrs = row_start_ptr + col_offsets
    mask = col_offsets < n_cols

    # Load entire row into SRAM registers
    row = tl.load(input_ptrs, mask=mask, other=-float("inf"))

    # Perform max, sub, exp, sum, div entirely in registers
    row_minus_max = row - tl.max(row, axis=0)
    numerator = tl.exp(row_minus_max)
    denominator = tl.sum(numerator, axis=0)
    softmax_out = numerator / denominator

    # Single writeback to global memory
    out_row_start_ptr = out_ptr + row_idx * out_row_stride
    tl.store(out_row_start_ptr + col_offsets, softmax_out, mask=mask)
kernels/vector_add.py Fundamental Grid & Masking Model 
@triton.jit
def _vector_add_kernel(
    x_ptr, y_ptr, z_ptr,
    n_elements,
    BLOCK_SIZE: tl.constexpr,
):
    pid = tl.program_id(0)
    block_start = pid * BLOCK_SIZE
    offsets = block_start + tl.arange(0, BLOCK_SIZE)
    mask = offsets < n_elements

    x = tl.load(x_ptr + offsets, mask=mask)
    y = tl.load(y_ptr + offsets, mask=mask)
    output = x + y
    tl.store(z_ptr + offsets, output, mask=mask)
Systems Design Principles

Hardware Memory & Execution Optimization

⚡

Kernel Fusion vs Eager Overhead

Standard PyTorch eager execution launches 4 sequential kernels for Soft-Dice Loss: elementwise multiplication and 3 separate .sum() reduction kernels. This forces 4 complete HBM global memory roundtrips. By fusing elementwise multiplication and partial reductions into a single Triton kernel pass, we eliminate ~75% of DRAM reads/writes.

🔲

2D Grid & Inter-Block Atomic Accumulation

Medical image tensors (e.g. 512×512 slices) contain ~262k elements per channel—far too large for a single threadblock's SRAM. We partition execution across a 2D block grid: Axis 0 tiles spatial chunks across blocks, while Axis 1 indexes slice channels. Multiple threadblocks accumulate partial sums into output buffers via lock-free tl.atomic_add.

🧠

SRAM Caching & Coalesced Memory Access

Utilizing vector loads (tl.load) with power-of-two padding ensures memory transactions align directly with GPU warp memory coalescing (128-byte transactions). Intermediate softmax values (max, exp, sum) stay strictly inside fast L1 cache / register files before writing output.
